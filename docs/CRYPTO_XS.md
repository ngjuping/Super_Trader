# Bybit 加密货币横截面（纸面）

这条路径回答的是横截面问题：在同一根已经收盘的 UTC 日线上，哪些交易对相对更强，纸面组合该怎么摆。它不是 BTC 单币择时，也不改 A 股的 `scan` / `accuracy` / `xs` / `fullfit`。

实盘下单没有实现。`--live` 无论有没有确认标记都会退出，并且不会读取密钥。

## 研究默认值，不是实盘批复

下面这些值是为了让纸面命令能够运行而写进仓库的。它们可以被命令行覆盖。它们不是用户确认过的宇宙、资金、杠杆或止损。

| 项目 | 纸面默认 | 说明 |
|---|---|---|
| 交易对 | `BTCUSDT ETHUSDT SOLUSDT XRPUSDT DOGEUSDT ADAUSDT AVAXUSDT LINKUSDT LTCUSDT BCHUSDT` | 只用于 `spot` 和 `linear`。这是一份当前名单，有幸存者偏差。`inverse` 没有默认名单 |
| 时钟 | UTC 日线，每天 24 小时，含周末 | 不用 A 股工作日 |
| 类别 | 无默认 | 必须写 `--category spot`、`linear` 或 `inverse` |
| 纸面权益 | 10,000 USDT | 只在本地账本里出现，不会划转 |
| 杠杆 | 无 | 配置里没有杠杆字段。总敞口默认不超过 1 |
| 费用 | 10 bps | 研究假设，不是账户费率 |
| 滑点 | 5 bps | 研究假设。买入按开盘上浮，卖出按下浮 |
| 最短历史 | 60 根已收盘日线 | 不够的币当天不参与排名 |
| 流动性 | 20 日成交额中位数 ≥ 1,000,000 USDT | 只用当天及以前的成交额 |
| 横截面最少个数 | 6 | 少于此数当天不交易 |
| 时间切分 | 前 50% 拟合，接着 25% 校准，最后 25% 测试 | 测试段不参与选规则 |
| 候选 | 回看 5/20/60，持有 1/5/20，每边 1/2/3 个 | 等权 |
| 单名上限 | 0.5 | 超出部分留在现金，不加到其他名字上 |
| 行情过期 | 最后一根收盘后超过 2 个 UTC 日 | 过期则不给待执行目标 |

`SOLUSDT` 出现在研究默认宇宙里，只表示用它的公开日线参加排名。程序不会查询或改动已有的 SOL 策略，也不会动 XAUT。XAUT 不在默认宇宙里。

## 信号怎么选

1. 特征是因果的：回看收益只用 `t` 和 `t-n` 的收盘，再减去当天合格交易对的中位数。
2. 拟合段只决定方向。秩相关均值为正用动量（做强的），为负用反转（做弱的）。均值不是正也不是负，或者有效天数不够，就放弃这条候选。
3. 校准段在已经锁定的方向下，用纸面权益挑选回看、持有和每边个数。平分时优先更少的成交额，然后更短的回看、持有和更小的篮子。
4. 测试段只记账，不再改规则。调用方如果用 `--lookback --horizon --top-k --direction` 把规则钉死，报告会标明这不是样本外挑选。
5. 不使用全历史拟合，也不会因为全样本低于 50% 就把方向翻过来。
6. 涨跌停、除权跳空剔除、月初月末和“下一根 K 线才知道的节假日”都不进入这条路径。

成交假设：信号使用当天收盘，成交使用下一根日线的开盘。持有根数默认等于选出的 horizon，可用 `--rebalance-every` 改。两次再平衡之间不设止损；止损和每日亏损上限仍要等用户确认，不能在这里猜。

现货目标权重全部 ≥ 0，加起来不超过总敞口上限，剩余是现金。现金不够支付买入和费用时，按比例缩小买单，不允许把现金做成负数，也不允许借币做空。线性合约和反向合约才做对称多空：多头合计 0.5、空头合计 0.5，总敞口 1，这是不加杠杆的纸面权重，不是交易所杠杆。永续资金费没有建模，报告里的纸面盈亏不含资金费。

排名并列时按交易对代码升序。同一信号的 `client_order_id` 由类别、交易对、信号 bar 和目标权重决定。同一 id 再次入账不会加仓。

行情来自 Bybit 官方公开接口 `GET /v5/market/kline` 和 `GET /v5/market/instruments-info`，主机 `https://api.bybit.com`。每次请求都带上调用方写明的 `category`。未收盘的日线会丢掉。上市时间之前的 bar 会丢掉，缺失的日期保持空值，不回填。这份名单看不到已经下架的合约。公开接口如果拒绝访问，命令直接失败，不会改去别的交易所，也不会转去私有接口。

## 命令

```powershell
python -m super_trader crypto-xs --category linear
python -m super_trader crypto-xs --category spot --symbols BTCUSDT,ETHUSDT --bars-json bars.json
python -m super_trader crypto-xs --category linear --live
```

第三条会失败退出。即使加上确认标记，这个构建仍然没有私有下单通道。

离线 JSON 的形状是 `{"as_of_ms": 0, "symbols": {"BTCUSDT": [{"start_ms": 0, "open": 1, "high": 1, "low": 1, "close": 1, "volume": 1, "turnover": 1}]}}`。里面如果写了 `leverage` 或 `live_capital_usdt`，命令会拒绝。

## 还没做，也不能靠默认值补上

- 实盘委托、签名、撤单、平仓、查询账户持仓
- 用户确认后的宇宙、市场、出资金额、杠杆和亏损上限
- 永续资金费、借币利息、强平
- 除等权以外的权重
- 日线以外的周期
- 把已退市合约补回历史
