# 探索性研究协议与修订记录

> 初稿后已多次查看数据并修改方法，不能将本轮结果称为预注册或确认性验证。
> 当前历史留出期也已被反复使用，最终候选必须等待新数据验证。
> 2026-11-06 周期修订：仅训练段按方向化毛超额收益/天选周期，基准不含留出标签；
> 训练与四折边界按原始bar净化；功效只提示，不通过放松显著性门槛平衡周期数量。
> 段内置换会破坏时间相关，仅为敏感性诊断。旧版“5倍信噪比”“17个已证实差异化标的”撤回为探索性线索。

## 2026-11-06：准确率优先模式（当前用户目标）

新增独立 `accuracy` 模式，不沿用下文旧研究模式的收益或p/FDR筛选条件。
每个标的与持有期独立：50%拟合规则准确评分、25%校准规则数与中性阈值、25%冻结后段评估。
所有切分净化前瞻标签跨界。规则数1/3/5/10，阈值0.50至0.90、步长0.05；默认拟合至少60次触发、校准至少30次预测。
目标函数为校准准确率，平分优先覆盖更多、规则更少；测试结果不反过来修改阈值。
收平保留，涨跌预测遇收平均计错；中性不算对也不算错。准确率必须同时附覆盖率和预测次数。
既有日期实现存在事后观察风险，暂排除月初、月末、节前规则。数据质量过滤会剔除未来窗口含价格重塑的样本，
因此报告分母是事后可标注的干净样本，不是所有实盘可发信号的时点。历史评估仍不是全新的未来验证。

## 1. 目标与边界

**要回答的问题**：在 A 股日线数据上，是否存在**可验证、可解释、跨标的稳定**的
「未来涨跌方向」规律？如果有，是什么？有多强？在什么条件下失效？

**不做的事**（避免自欺）：

- 不做收益率/夏普/资金曲线回测——本研究只评估**方向命中率**，不是交易系统。
- 不做参数寻优。规则阈值是事先设定的整数档（0.3/0.5/1.0 ATR 等），不搜最优参数。
- 不做机器学习黑箱。80 条以内可解释规则，每条能用一句中文说清。
- 不承诺未来收益。所有输出都是**历史频率**，不是概率校准，更不是盈利保证。

## 2. 数据与样本

- 来源：`D:\A股k线数据\多周期\日线\{指数|ETF|个股}`，不复权，东财公开行情。
- 覆盖：2005-01-01 起（股改后、涨跌停与 T+1 制度稳定期），至数据最新交易日。
- 预热：每标的最前 120 根只用于算特征，不产生样本。
- 最短历史：单标的不足 1000 根不入选（样本不足时任何结论都不可靠）。
- 标的池：`mainstream`（62 个）= 10 宽基指数 + 14 行业指数 + 14 主流 ETF + 24 龙头个股。

### 除权/价格重塑防护

个股与 ETF 为**不复权**，分红送转会制造价格跳变。凡是单日跳空超过「涨跌停幅度+1.2
个百分点」的 bar（主板 >11.2%、创业板/科创板 >21.2%、北交所 >31.2%）判定为价格重塑
事件（`artifact_mask`），任何横跨该 bar 的前瞻窗口**整段剔除**，避免把除权跌幅算成
「预测正确的下跌」。

## 3. 信号与前向收益

在第 i 根 bar 收盘后计算规则信号 `s_i ∈ {+1, 0, -1}`，只使用 `≤ i` 的信息（所有比较类
特征对历史 `shift(1)`，滚动窗口含当根）。

- 预测口径：`r_cc = close[i+h] / close[i] - 1`
- 可执行口径：`r_oc = close[i+h] / open[i+1] - 1`（A 股 T+1，最早次日开盘成交）
- 命中：`sign(r) == s_i`；`r == 0`（收平）不计入样本。
- 周期 h ∈ {1, 3, 5, 10, 20} 个交易日。

## 4. 显著性：三个必须做的修正

1. **基准不是 50%**。A 股 2005 年后指数日涨概率约 53%，用 50% 做零假设会凭空造出
   「3 个百分点优势」。零假设取 `p0 = 该标的该窗口的无条件上涨概率`；空头信号对应
   `1 - p0`。混合方向的规则用触发次数加权得到混合 `p0`。
2. **重叠窗口修正**。h 日窗口在相邻信号间重叠 h-1 天，n 个信号的有效独立样本量约
   `n_eff = n / h`。p 值按 `n_eff` 计算（`binom_p_upper(acc, n_eff, p0)`）。不做这一步，
   长周期规则会大规模假显著。
3. **多重检验**。同时对 80 条规则 × 5 个周期做检验，用 Benjamini–Hochberg 控制 FDR。

## 5. 先选后验：训练段 / 留出段 / 市场阶段

按时间切分，**不重叠、不看未来**：

- 训练段 = 评估区前 60%；留出段 = 后 40%。
- 市场阶段：2005–2009 / 2010–2014 / 2015–2019 / 2020–2024 / 2025– 。用于检验「规律是否
  只在某一轮牛市里成立」。

## 6. 两条验收线

### A. 规则级：「这是不是一条市场规律」

对每个（规则 × 周期），在全部标的上统计留出段优势的方向一致性：

| 条件 | 阈值 | 理由 |
|---|---|---|
| 有效标的数 | ≥ 20 | 少于 20 个标的谈不上「跨标的」 |
| 优势为正的标的占比 | ≥ 65% | 不是靠一两个标的撑起来 |
| 符号检验 p | ≤ 0.01 | 65% 一致在 20~60 个标的上很难靠运气 |
| 跨规则 FDR q | ≤ 0.10 | 380 个（规则×周期）同时检验 |
| 平均留出段优势 | > 0.5 个百分点 | 太小的优势扣掉成本即归零 |
| 优势的 bootstrap 95% 下界 | > 0 | 均值不能被少数标的拉起来 |
| 阶段稳定 | ≥ 60% 的市场阶段优势为正 | 不是只在某一段行情有效 |

### B. 标的级：「这个标的现在有规律可用」

| 条件 | 阈值 |
|---|---|
| 训练段：触发 ≥ 60 次，优势 > 0，p ≤ 0.10 | 入选 |
| 留出段：触发 ≥ 30 次，优势 > 0，p ≤ 0.05 | 确认 |
| 阶段稳定 | ≥ 60% 阶段为正 |

**预期假发现**：训练段入选的规则里，约 `留出段 p 阈值`（5%）会在留出段「碰巧」通过。
因此报告必须同时给出 `晋级数 / 预期假阳性`，比值接近 1 时，结论是「没找到规律」。

## 7. 失败判定（什么情况下必须说「没找到」）

只要满足以下任意一条，结论就必须写「本轮没有可用的稳定规律」：

- 规则级 A 线全数为 0；
- 晋级数与预期假阳性同量级（比值 < 3）；
- 最强规则的优势无法覆盖 A 股双边交易成本（指数 ETF 约 0.02%~0.05%，个股约 0.1%~0.3%
  加印花税），或优势只在 H1 成立而 H1 又低于成本。

## 9. 已知局限

1. **不复权数据**：除权日已剔除，但长期分红导致的「价格中枢下移」无法还原，个股类结论
   弱于指数类结论。
2. **幸存者偏差**：数据只含当前仍在市的标的，退市/长期停牌股不在内，个股类命中率可能偏高。
3. **涨跌停无法成交**：H1 的可执行口径未剔除「次日一字涨停买不进」的情形，实盘会打折。
4. **成交成本与冲击**：本研究完全不考虑费用、冲击成本与容量。
5. **市场结构变化**：注册制、量化交易占比上升、涨跌停改为 20% 等制度变化会削弱历史规律。
6. **重叠样本仍有残差相关**：`n_eff = n/h` 是保守近似，不是精确的有效样本量。
7. **HAC 不是万能**：Newey-West 对「长记忆 / 结构性断裂」只能部分吸收；`lag=21` 是
   经验选择，规格曲线里会换 5/63 复核。

## 10. 修订记录

### r3（2026-11-05，跑完第一轮之后）

发现并修正一个真实缺陷：`month_end` 原先用「数据里的下一根 K 线」判定，导致**最新一根
K 线永远被当成月末**，实盘信号会每天喊「月末买」。改为：已走完的月份按数据取最后 2 根
交易日，当前未走完的月份用交易所工作日历判定。**该缺陷只影响实盘信号，不影响回测**
（回测里 h≥1 的前瞻窗口本来就用不到最后一根）。

同时把「信号 bar 本身是除权 bar」也纳入剔除（原先只剔除前瞻窗口内含除权 bar 的样本）。

### r2（2026-11-05，实现过程中）

以下是**收紧**而非放宽，全部在跑出最终结论前完成，并逐条说明理由：

1. **显著性检验从「符号检验」改为「市场级 HAC 检验」**。原协议用「62 个标的中多少个
   优势为正」做符号检验。实现后发现这是错的：A 股各标的日收益相关性极高，62 个标的不
   是 62 次独立实验，符号检验会把显著性放大一个数量级。改为把同一天压成一个观测、
   在时间维度做 Newey-West HAC 检验。跨标的一致性仍然保留，但降级为**描述性稳健性指标**，
   不再作为显著性依据。
2. **基准改为逐标的的无条件命中率**。原协议已写「该标的该窗口的无条件上涨概率」，实现中
   先误用了全局常数，后按原意改回逐标的——否则「规则偏爱创业板」这类标的构成差异会被
   误读成预测能力。
3. **新增规格曲线**。同一份数据 × 2 种基准口径 × 3 个 HAC 滞后 × 2 个每日最少信号数
   = 12 种设定，要求 75% 以上通过。原因：单点设定下的显著性太容易被研究者自由度左右。
4. **假阳性基线从公式估算改为安慰剂实测**。原协议用「训练段入选数 × 留出段 p 阈值」粗估，
   这个公式忽略了重叠修正和方向一致性条件，严重高估期望假阳性（算出 73.7，实测安慰剂
   只有 0.37%）。改为：随机平移标签、同流程重跑、得到经验晋级率，再与真实晋级率比较。
5. **验收线 A 增加「触发日 ≥100 天」**，防止 36 个交易日的稀有事件靠运气通过。

未变的部分：前瞻收益定义、训练/留出按时间切分、留出段 p≤0.05、FDR、阶段稳定、
「命中率不等于盈利」的表述方式。
