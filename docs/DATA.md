# 数据规格与已知问题

## 1. 来源与目录

本地存档（本机路径 `D:\A股k线数据`，由东财 `push2his` 公开接口下载）：

```
{data_root}/
  个股/600519_贵州茅台.csv
  ETF/510300_沪深300ETF华泰柏瑞.csv
  指数/000001_上证指数.csv
```

`config.json` 的 `data_root` 需要指向**日线**这一层（默认 `D:\A股k线数据\多周期\日线`）。
同一目录下也可以放其它周期（周线、60分钟…），本项目当前只读日线。

## 2. 字段

| 字段 | 含义 | 备注 |
|---|---|---|
| date | 日期 | 日线 `YYYY-MM-DD`，分钟线 `YYYY-MM-DD HH:MM` |
| open/high/low/close | 开高低收 | **不复权**原始价 |
| volume | 成交量 | 东财口径「手」（指数为成分股累计） |
| amount | 成交额 | 元 |
| amplitude | 振幅 | % |
| pct_chg | 涨跌幅 | %（与 close-to-close 一致） |
| change | 涨跌额 | 元 |
| turnover | 换手率 | %（指数通常为 0） |

编码 UTF-8 with BOM，按时间升序，一行一根 K 线。

## 3. 读入时做的清洗

`data.py::KlineStore._read_csv` 按顺序执行：

1. 校验必需列存在，缺列直接报错（不静默补零）。
2. `date` 转 datetime，OHLC/量额转数值；`date`/`open`/`high`/`low`/`close` 缺失的行删除。
3. 删除 `close <= 0` 的行（不复权数据里前复权会出现负价，不复权不应出现）。
4. 删除 `high < low` 的行。
5. 同一天重复时保留最后一条，按日期升序。
6. `volume`/`amount` 负值截断为 0。
7. 写 parquet 缓存，用源文件 `mtime + size` 做失效判断。

清洗是**删行**而不是插值——插值会制造不存在的 K 线，直接污染前瞻收益。

## 4. 除权 / 价格重塑识别（重要）

个股与 ETF 为**不复权**。分红、送转、配股、复牌都会在价格上留下一个跳空，这个跳空
不是「市场下跌」，但会被方向命中率当成「预测正确的下跌」。

判定规则（`data.py::artifact_mask`）：

```
|open_t / close_{t-1} − 1| > 涨跌停幅度 + 1.2pp   或
|close_t / close_{t-1} − 1| > 涨跌停幅度 + 1.2pp
```

- 主板：> 11.2%
- 创业板 / 科创板：> 21.2%
- 北交所：> 31.2%
- ETF：> 11.2%
- 指数：不判定（价格指数无除权）

被标记的 bar 以及**任何横跨该 bar 的前瞻窗口**都从统计中剔除。

这只是一个近似：如果某天正好是除权日又叠加了 9% 的真实下跌，跳空幅度可能仍小于阈值，
这种样本会被漏掉。反过来，连续涨跌停（ST 股、次新股）也可能被误判为除权。

## 5. 交易日历

`month_end` / `month_start` 优先用**数据里的交易日序列**（最贴合真实节假日安排）：

- 已走完的月份：该月最后/最前 2 根交易日。
- 数据首月与末月：改用交易所工作日历（pandas `bdate_range`）判定，因为首月可能从月中
  开始、末月还没走完。

**为什么必须这样做**：早期版本用「数据里的下一根 K 线是否跨月」判定，结果**最新一根
K 线永远被判定为月末**——回测没事（h≥1 用不到最后一根），但实盘信号会每天亮「月末买」。

`pre_holiday` / `post_holiday` 用相邻 K 线间隔 ≥4 个自然日判定，天然不受数据长度影响。

## 6. 已知数据问题

1. **停牌**：长期停牌会造成相邻 K 线间隔很大，`suspension_mask` 可以识别（默认 >15 天），
   但本项目当前没有剔除停牌样本——停牌前后的价格跳变会进入统计。
2. **新股**：上市首日及前若干日没有涨跌停约束、价格由发行价跳到市场价，跳空远超阈值，
   会被 `artifact_mask` 标记剔除，这是想要的行为。
3. **指数成交额**：部分指数 `amount` 为 0 或缺失（如中韩半导体 931790 全为 0），
   量能类规则在这种标的上等价于「永远不触发」。
4. **分钟线只有 32 个交易日**：东财接口限制，无法回溯。日线无此问题。
5. **最后一根 K 线**：如果下载时是盘中，最后一根是未收盘数据。扫描前请确认数据在收盘后
   刷新过（`summary.json` 的 `market_date` 会显示实际用的最后交易日）。

  伊利股份 15、格力电器 12…）；10 个宽基指数与 14 个行业指数均为 0（价格指数无除权，符合预期）。
- 停牌缺口 82 处。
- 零成交 bar 0 根。
