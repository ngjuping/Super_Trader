# Super_Trader

**A 股日线「未来涨跌」量化规律挖掘平台** —— 不是又一个回测框架，而是一套
「先证伪、再相信」的规律检验流程。

> 本项目只研究**方向**（未来 N 天涨还是跌），不做交易系统，不算收益率曲线，
> 不承诺任何收益。所有结论都是**历史频率**，不是概率预测。
> 仅供研究学习，不构成投资建议。

---

## 它回答什么问题

给定一篮子 A 股主流标的的日线数据，问三个问题：

1. 存不存在**可解释、可复现**的「未来涨跌」规律？
2. 如果有，它在**换标的、换时间段、换统计设定**之后还站得住吗？
3. 它到底是「真规律」，还是多重检验 + 重叠样本 + 横截面相关造出来的幻觉？

第 3 个问题是重点。绝大多数「量化规律」都死在这里。

## 第一轮结论（2026-11-05 数据）

跑完 **62 个主流标的 × 78 条规则 × 5 个周期 = 22,895 次检验**后：

**只有 5 条规则通过了全部验收**（跨标的符号一致 ≥65% + 市场级 HAC 检验 p≤0.01 且
FDR q≤0.10 + 12 种规格设定下 ≥75% 通过 + 60% 以上市场阶段为正）：

| 规则 | 周期 | 市场级方向优势 | 多头每笔净优势 | 触发频率 |
|---|---|---|---|---|
| 月末最后 2 个交易日看涨 | H3 | +7.30pp | +50.1bp | 9.9% |
| 月末最后 2 个交易日看涨 | H1 | +6.16pp | +24.8bp | 9.9% |
| 连跌 5 日后看涨 | H1 | +10.00pp | +13.0bp | 2.3% |
| RSI(2) 极端反转 | H1 | +2.79pp | +2.2bp | 26.8% |
| 布林 %B 极端反转 | H1 | +2.17pp | −2.6bp | 18.5% |

三个必须知道的事实：

- **标的级筛选基本是噪声**。22,895 次检验里有 122 条「晋级」，但把收益标签随机平移后，
  同样的流程仍会晋级 0.365%（真实 0.533%）。比值 1.46×——所以本项目**不把任何
  「某个标的的某条规则」当结论**。
- **趋势/突破类在日线层面不成立**。8 条趋势规则、6 条突破规则，0 条通过验收。
  日线级别的 A 股更像「震荡市」，均值回归 > 动量。
- **命中率高 ≠ 能赚钱**。布林带外规则的命中率优势显著，但做多后的平均收益反而低于
  无条件持有——它的优势全在「躲跌」那一侧，而 A 股多数账户不能做空。

完整报告：`reports/mainstream_daily/report.html`（单文件，双击打开）。

## 快速开始

```powershell
# 1) 安装依赖（Python 3.10+）
pip install -r requirements.txt

# 2) 指向你的日线数据目录（默认 D:\A股k线数据\多周期\日线）
copy config.example.json config.json
#    编辑 config.json 里的 data_root

# 3) 一条命令跑完：扫描 + 生成报告
python -m super_trader scan

# 4) 看今天各标的的规则信号
python -m super_trader predict
```

其他子命令：

```powershell
python -m super_trader check             # 数据体检：行数、区间、除权跳变、停牌缺口
python -m super_trader rules             # 列出 78 条规则
python -m super_trader placebo           # 安慰剂检验（打乱标签后还剩多少「规律」）
python -m super_trader report            # 用已有 results.json 重新生成报告
python -m pytest -q                      # 55 项单元测试
```

扫描全市场（8,228 个标的）时用 `--pool auto --top 200`；只跑指数用 `--pool 宽基`。

## 数据

详见 `docs/DATA.md`。要点：

- 目录：`{root}/{个股|ETF|指数}/代码_名称.csv`，UTF-8 BOM，按时间升序。
- 字段：`date, open, close, high, low, volume, amount, amplitude, pct_chg, change, turnover`。
- **不复权**。分红送转造成的价格重塑 bar 用「单日跳空 > 涨跌停+1.2pp」识别，
  落在前瞻窗口内的样本整段剔除，避免把除权跌幅算成「预测正确的下跌」。
- 缓存：首次读取后写 `data/cache/*.parquet`，源文件 mtime/size 变了会自动失效。

```
  features.py    约 50 个特征（趋势/波动/位置/量能/形态/缺口/日历/涨跌停）

  evaluate.py    标的级评估 + 市场级面板（同日压成一个观测）+ 规格曲线
  universe.py    主流标的池（10 宽基 + 14 行业 + 14 ETF + 24 龙头）
  scan.py        编排：跑池子 → 汇总 → 选规则 → 落盘
  report.py      单文件 HTML 报告 + Markdown 结论
  predict.py     把规则套到最新一根 K 线上（今日信号）
  diagnose.py    数据体检 + 安慰剂检验
  cli.py         命令行入口
docs/
  PROTOCOL.md    预注册的研究协议（先定口径，再看结果）
  DATA.md        数据规格与已知问题
tests/           55 项测试，含「无未来函数」硬约束与统计机制校准
```

## 方法论：三道防线

### 1. 基准不是 50%

A 股 2005 年后指数次日上涨概率约 **51~53%**。用 50% 当零假设，任何随机规则都会凭空
获得 2~3 个百分点的「优势」。本项目对每个标的、每个周期，用**它自己的无条件上涨概率**
做基准。

### 2. 重叠窗口

h 日前瞻收益在相邻信号之间重叠 h−1 天：1000 个「样本」里其实只有约 1000/h 个独立观测。
不修正，H20 规则会大规模假显著。本项目在标的级检验里按 `n_eff = n / h` 折减。

### 3. 横截面相关

A 股同涨同跌，62 个标的不等于 62 次独立实验。把「所有标的的命中率」加起来做二项检验，
会得到一个漂亮但虚假的 p 值。本项目的**市场级检验**先把同一天压成一个观测：

```
acc(t)  = 当日全部触发信号的方向命中率
base(t) = Σ 触发标的各自的无条件命中率 / 触发数
edge(t) = acc(t) − base(t)
```

再对 `edge(t)` 的均值做 **Newey-West HAC** 检验（滞后 ≥ 21 个交易日），
独立性单位回到「时间」而不是「标的」。

### 4. 规格曲线

结论不该依赖「基准怎么取 / HAC 滞后几阶 / 每天至少几个信号」。本项目把这些选择做成
12 种合理组合各跑一遍，规则必须在 75% 以上的设定下依然通过。

### 5. 安慰剂

把「未来是否上涨」的标签在时间轴上随机平移（保留自相关结构），信号与门槛不动，重跑
同一套流程。真实晋级率与安慰剂晋级率的比值，就是这套流程「真的发现了什么」的程度。

## 局限（请务必读完）

1. **不复权数据**：除权日已剔除，但长期分红导致的价格中枢下移无法还原，个股结论弱于指数。
2. **幸存者偏差**：数据只含当前仍在市的标的，退市/长期停牌股不在内，个股命中率可能偏高。
3. **涨停买不进**：H1 的可执行口径没有剔除「次日一字涨停」的情形，实盘会打折。
4. **成本与容量**：完全没有计算佣金、印花税、滑点、冲击成本。
5. **制度变化**：注册制、涨跌停改 20%、量化占比上升，都会削弱历史规律。
6. **样本量**：有些规则（如连跌 5 日）只有 140 个市场观测，效应量大但置信度有限。
7. **`n_eff = n/h` 是近似**，不是精确的有效样本量。
