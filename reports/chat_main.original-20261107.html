主信号 · Brooks 突破顺势 唯一经验证存活的规则

突破窗口 N = 20 入场 次根开盘 止损 swing 外侧 0.1 ATR 最小风险 0.5 ATR 目标 2 : 1

收盘价上破前 20 根最高收盘 → 做多；下破前 20 根最低收盘 → 做空。止损放最近已确认 swing 的外侧，目标为风险的 2 倍。这不是「涨了就追」——同数据上简单动量 edge≈0， 而突破顺势有 +0.1~0.2R 的微弱正期望，说明「突破前 N 根极值」这个结构带了信息。

诚实声明 先证伪再相信

Brooks 突破顺势状态为「可能有效，未达实盘门槛」：三组对比验证（A 规则 / B 全随机 / C 位置匹配）里， XAUUSD H4、USDJPY H4、US500 D1 显示微弱正期望，但——
  • 参数稳健性仅 2/5（只有 N=20、25 有效，参数悬崖，过拟合嫌疑）
  • 跨品种存活率 3/9（更像「金价/日元这几年强势」的特定历史）
  • 效应量 +0.2R 很薄，扣点差滑点后可交易空间窄
A 股日线能否复现尚需用同一套三组对比框架重测。此页为价格行为读图的结构示意，不构成买卖信号。
